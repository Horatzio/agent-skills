Agent Skills

Skill loader for Horatzio/agent-skills.

Load a skill with any of these forms:

  • load?s=wizard
  • load?skill=wizard
  • load/wizard

Local skills (in the repo) win over referenced skills on a name clash. The registry is skills.json, generated from REFERENCES.md plus the repo's own skills. Agents: fetch skills.json, look up the name, then fetch that entry's raw_url (the skill's SKILL.md) and follow it.
